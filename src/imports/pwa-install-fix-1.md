# Fix: PWA Install Prompt Not Working

## Problem

DuoReel has `public/manifest.json` and `public/sw.js` but neither is wired into the app.

| Issue | Impact |
|---|---|
| No `<link rel="manifest">` in `index.html` | Browser never discovers manifest — no install prompt |
| Service worker never registered | `sw.js` sits idle, offline mode doesn't work |
| SVG-only icons in manifest | Chrome/Android requires PNG icons to trigger installability |

---

## Change 1 — `index.html`

**Find:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
<title>Movie Discovery App</title>
```

**Replace with:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
<meta name="theme-color" content="#0f172a" />
<meta name="mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent" />
<meta name="apple-mobile-web-app-title" content="DuoReel" />
<link rel="manifest" href="/manifest.json" />
<link rel="apple-touch-icon" href="/icons/icon-512.png" />
<title>DuoReel</title>
```

---

## Change 2 — `src/main.tsx`

**Find:**
```typescript
createRoot(document.getElementById("root")!).render(<App />);
```

**Replace with:**
```typescript
createRoot(document.getElementById("root")!).render(<App />);

// Register PWA service worker
if ('serviceWorker' in navigator) {
  window.addEventListener('load', () => {
    navigator.serviceWorker
      .register('/sw.js')
      .catch((err) => console.warn('SW registration failed:', err));
  });
}
```

**Find:**
```json
"icons": [
  {
    "src": "/icons/icon.svg",
    "sizes": "any",
    "type": "image/svg+xml",

  {
    "src": "/icons/icon-maskable.svg",
    "sizes": "any",
    "type": "image/svg+xml",
    "purpose": "maskable"
  }
```

**Replace with:**
```json
"icons": [
  {
    "src": "/icons/icon.svg",

    "type": "image/svg+xml",
    "purpose": "any"
  },
  {

  {

    "sizes": "192x192",
    "type": "image/png",
    "purpose": "any"
  },
  {
    "src": "/icons/icon-512.png",
    "sizes": "512x512",
    "type": "image/png",
    "purpose": "any maskable"
  }
]
```

## Manual Step (before or after prompt)

Two PNG files must be added to `public/icons/` in the repo — these cannot be generated by Figma Make:

- `public/icons/icon-192.png` — 192×192px
- `public/icons/icon-512.png` — 512×512px

These files have been pre-generated and are available for download. Commit them directly to the repo at `public/icons/`.
