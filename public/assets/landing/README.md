# Landing Page Assets

Static images served from this folder are available at:
`https://duoreel.com/assets/landing/{filename}`

## Expected files

| File | Used in |
|------|---------|
| `app-screenshot.png` | Hero section — right column mock app visual |
| `og-image.png` | Open Graph / social share preview image |

## How to add images

1. Drop the image file into this folder
2. Commit and push to the repo
3. The image is immediately live at `https://duoreel.com/assets/landing/{filename}`

No code changes needed — paths are already wired in `LandingPage.tsx`.
